## 🔴 About This Repository

> **NTU CITS Media Assets** provides a centralised location for organising and maintaining digital assets used across CITS-related web and communication channels.

The repository helps ensure that media assets are:

- Consistently organised
- Easy to locate and maintain
- Suitable for official NTU digital platforms
- Properly versioned where required
- Aligned with NTU’s digital and branding standards
